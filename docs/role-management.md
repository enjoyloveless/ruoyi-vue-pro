# 三员管理（SM、SC、AM）

本章节说明如何按照国家等级保护等要求，将管理权限划分为系统管理员、安全管理员和审计管理员三类角色。通过合理配置角色与权限，可以防止单一管理员拥有过大的控制权限。

## 系统管理员（SM）
- 对应等保条款：**A.4 系统构建 → 系统管理**
- 职责：资源和服务配置、系统运行维护、备份与恢复等
- 典型权限：系统设置、服务部署、系统维护相关菜单

## 安全管理员（SC）
- 对应等保条款：**A.4 系统构建 → 安全管理**
- 职责：账户授权、策略配置、漏洞修补、应急处置
- 典型权限：权限管理、策略设置、安全补丁管理等

## 审计管理员（AM）
- 对应等保条款：**A.5 安全运维 → 安全审计**
- 职责：审计策略制定、日志留存、防篡改、违规分析
- 典型权限：审计日志查看、审计策略配置等

## 权限配置建议
1. 在管理后台中分别创建 SM、SC、AM 三个角色，并仅授予其对应的菜单和功能权限。
2. 建议由不同人员分别担任各角色，避免单人拥有过大的系统权限。
3. 定期检查各角色的权限分配，确保符合最小权限原则，满足国家标准要求。
